THƯ MỤC TÀI NGUYÊN (ASSETS) – SOCIALISM LEGENDS
================================================
Toàn bộ đồ họa Dark Fantasy (5 vùng đất, 21 quái vật, 5 Boss, thẻ kỹ năng, hiệu ứng hạt)
và âm thanh chiến đấu đã được tích hợp sẵn bằng SVG, HTML5 Canvas 2D và Web Audio API
để game chạy mượt 100% offline khi mở trực tiếp file index.html.

Các thư mục con (backgrounds, monsters, bosses, characters, icons, effects, audio)
được mở sẵn để bạn có thể bổ sung ảnh PNG hoặc âm thanh MP3 tùy biến trong tương lai.
